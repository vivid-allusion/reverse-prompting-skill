# The words

| Word | Means |
|---|---|
| **Animatic** | The film as one cheap generated still per shot, in order |
| **Reverse prompting** | Taking each still apart into the assets a video model needs: [[method]] |
| **Scene** | One continuous place and time; one or many shots: [[scenes]] |
| **Shot** | One still; one camera set-up |
| **Beat** | A run of a scene's shots made in one video generation |
| **Element** | Anything that must be in front of the camera, with one `@NAME` |
| **Hero** | Who or what a shot is about, and what they handle, wear or ride: [[hero]] |
| **Background** | Everything else; named in the video prompt, never made |
| **Canon** | A recurring element's truth sheet, in `_CANON/`: [[canon-and-state]] |
| **State** | How a canon element is in one scene |
| **Plate** | A place with nobody in it, from one camera side, in the project's look |
| **Sheet** | A character, costume or extras reference picture |
| **Pick** | The take the person keeps for an asset |
| **Coverage** | The table of every hero element and what makes it: [[coverage]] |
